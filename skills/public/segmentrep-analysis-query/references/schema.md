# Schema 说明

当前 schema：`segmentrep_analysis_v2`

问数产品默认只使用两张表：`数据宽表` 和 `原始YTD事实表`。

## `数据宽表`

用途：

- 标准口径最终问数入口
- 标准架构、标准科目、ABF、趋势、达成率、成长率、经营情况
- 标准结果的轻量来源解释

粒度：

- `年份 + 标准架构键 + 标准架构层级 + 标准科目名称 + 场景角色 + 场景年份`

关键字段：

- 标准架构：`标准事业群`、`标准事业部`、`标准产线1`、`标准架构键`、`标准架构名称`、`标准架构层级`
- 标准科目：`标准科目名称`
- 场景：`场景角色`、`场景年份`
- 原始来源：`原始架构名称`、`原始架构层级`、`原始架构键`、`原始科目列表`、`来源记录数`
- 期间：`1月` 到 `12月`、`1Q` 到 `4Q`、`1H`、`2H`、`YTD`

层级值：

- 常见为 `事业群级`、`事业部级`、`产线级`。
- 查询标准架构时尽量同时限定 `标准架构名称` 和 `标准架构层级`，避免同名不同层级混淆。

## `原始YTD事实表`

用途：

- 原始口径最终问数入口
- `Total`
- 历史原始块头、历史原始科目
- 原始报表还原

粒度：

- `年份 + 原始架构名称 + 原始科目名称 + 原始场景标签`

关键字段：

- 来源定位：`来源sheet`、`块序号`、`块头行号`、`科目行号`
- 原始口径：`原始架构名称`、`原始科目名称`
- 场景：`原始场景标签`、`场景角色`、`场景顺序`、`场景年份`
- 期间：`1月` 到 `12月`、`1Q` 到 `4Q`、`1H`、`2H`、`YTD`

## 非默认表

`年度架构匹配表`、`年度科目匹配表` 只用于刷新、排查和建模核对。普通问数不使用。
