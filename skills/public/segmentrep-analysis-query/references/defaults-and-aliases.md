# 默认认知与别名归一化

查询前先把用户自然语言归一化为数据库可查参数。默认值要在回答里轻量说明。

## 架构别名

- `CRF`、`CRF合并`、`长润发合并`：标准口径默认归一为 `长润发`；原始口径可保留 `长润发合并`。
- `I8`：标准口径默认归一为 `I8-TU`。
- `TU`：表示所有事业群，不等同于 `TU-HQ`。默认经营分析可展开为 `TUC`、`TUB`、`长润发`、`Factory`、`TU-HQ`、`I8-TU`，并可补充 `Total`。
- `总计`、`总盘子`、`Total`：默认查原始表 `原始架构名称 = 'Total'`。

用户明确说“原始块头”“原始口径”“按原表”时，不要静默改成标准名称，优先按 `原始YTD事实表` 查询。

## 指标别名

- `收入` = `TOTAL NET SALES`
- `PBT` = `PROFIT BEFORE TAX`
- `PBT%`、`PBT率`、`税前利润率` = `PROFIT BEFORE TAX / TOTAL NET SALES`

`PBT%` 是派生指标。要分别取 PBT 和收入后计算，并用 `NULLIF(收入, 0)` 保护分母。

## 时间默认

- 未指定年份：默认当年。
- 当前、今年、当年、最新、本年、现在、目前：默认当年标准口径。
- 未指定期间：默认当前报表当月。
- 当月：使用当前报表语境中的月份；如果上下文没有月份，先简短确认或说明无法判断。
- 累计、YTD：默认字段 `YTD`。
- 当前语境是 3 月时：当月 = `3月`；累计可表达为 `1-3月累计 / YTD / 1Q`，查询默认仍优先用 `YTD`。

## 场景默认

- 用户未指定 Actual / Budget / Forecast：普通问数默认 `场景角色 = '实际'`。
- 达成率默认：`实际 / 预算`。
- 成长率默认：`(当期实际 - 对比实际) / 对比实际`。

## 数值格式

- 百分比指标：保留 1 位小数，例如 `12.3%`。
- 金额相关指标：保留整数。
- 原始值为空或分母为 0：不要编造结果，说明没有有效分母或无数据。
