# 立邦模板风格指南

用于生成默认立邦集团简报风格 PPT。

## Assets

资产目录：`assets/nippon_style/`

- `cover-white-left-blue.jpeg`：封面背景。
- `footer-slogan-bar.png`：正文页底部品牌口号条。
- `nippon-logo.png`：正文页左上 logo。
- `blue-section-background.jpeg`：章节/过渡页背景。
- `closing-slogan-background.jpeg`：结束页背景。

## Page System

- 尺寸：16:9 wide，`13.333 x 7.5 in`。
- 字体：中文默认 `微软雅黑`。
- 标题：`24 pt`，深蓝 `#00378A` 或 `#00388B`。
- 正文/注释：`9-11 pt`。
- 正文安全区：约 `x=0.42-12.85 in`，`y=0.85-6.72 in`。

## Colors

- 深蓝：`#00378A`、`#00388B`、`#0F318A`、`#123A8D`
- 数据蓝：`#006ECF`、`#0753B8`、`#0B51AB`
- 亮蓝：`#1E6DC1`、`#3176BF`
- 强调红：`#E60012`、`#C51A44`
- 强调橙黄：`#FF6A00`、`#FFC000`
- 紫色过渡：`#4A298A`
- 弱线/浅底：`#E6EEF7`、`#D9E6F5`
- 背景：`#FFFFFF`

## Layouts

### Cover

- `cover-white-left-blue.jpeg` 铺满全页。
- 标题放右侧白色区域，避开左侧蓝色曲面和右下角橙红曲线。
- 标题 `28-36 pt`，副标题 `14-18 pt`。

### Content

- 白底。
- `nippon-logo.png` 放左上，约 `0.70 x 0.43 in`，位置 `x=0.50 in, y=0.24-0.35 in`。
- 标题从 logo 右侧开始，位置约 `x=1.65-1.75 in, y=0.25-0.33 in`。
- 可在右上放单位/币种标签，`9-11 pt`。
- `footer-slogan-bar.png` 贴底铺满宽度，高度约 `0.36-0.38 in`。
- 页码放右下角页脚条内，白字、小号、右对齐。

### Section

- `blue-section-background.jpeg` 铺满全页。
- 只放少量白字或浅蓝字；不放密集表格或图表。

### Closing

- `closing-slogan-background.jpeg` 铺满全页。
- 不叠加大段文字。

## Data Pages

- 表格表头用深蓝底白字，边框细。
- 图表和表格保持平面企业简报风格，少用厚重卡片、阴影和装饰。
- 多图页用上下或左右分区，分区线用浅蓝灰。
- 注释放页脚上方或右下角，不能进入 footer bar。
- 内容过密时拆页，不压缩 logo 区、标题区或页脚区。

## Layering

- 可作为图片层：背景、logo、footer bar、装饰纹理。
- 必须可编辑：标题、正文、数据、表格、图表标签、单位、注释、页码。
