# Segment 经营分析问数

这是一个纯问数 skill。只负责理解业务口径、生成查询、解释结果。不要读取 Excel 源文件，不要做数据入库，不要修改数据库结构。

## 工作流

1. 解析用户问题中的时间、组织范围、指标、数据类型和输出形式。
2. 用默认口径补齐缺失信息。
3. 先判断是否命中当前 skill 内的规则块；需要字段名时读取 `references/schema.md`，需要指标中文名或别名时读取 `references/metric_names.md`。
4. 使用可用的 PostgreSQL 数据库查询工具查询 `public.seg_all_year`。
5. 用中文输出结论、关键依据和必要口径。

## 数据源

- 数据库：`Segmentrep`
- 表：`public.seg_all_year`
- 表类型：单表经营分析事实表
- 查询方式：使用数据库查询工具执行 SQL
- `data_type` 枚举值：`实际`、`预算`

## 规则路由

- 一般问数：
  直接使用默认口径、维度规则和回答规则。
- 需要 SQL 字段名或确认列结构：
  读取 `references/schema.md`。
- 需要指标中文名、别名或展示名称：
  读取 `references/metric_names.md`。
- 需要简化利润表：
  使用本文件中的“输出规则”。
- 需要低层级维度分析：
  使用本文件中的“维度规则”。
- 需要预算、实际、同比或达成率：
  使用本文件中的“默认口径”和“时间规则”。

## 默认口径

- 未说明年份时，默认当前年份。
- 未说明实际/预算/同期时，默认 `data_type = '实际'`。
- 用户明确问预算时，使用 `data_type = '预算'`。
- 用户问实际 vs 预算、预算差异、预算达成率时，同时查询 `实际` 和 `预算`。
- 用户问“同期”或“同比”时，默认使用上一年相同 `period` 的实际值。
- 未说明组织范围时，默认所有事业部的 `TOTAL` 范围。
- 用户问“收入”时，默认指标是 `TOTAL NET SALES`。
- 用户问“利润”且未说明利润类型时，默认指标是 `PROFIT BEFORE TAX`。
- 用户问“利润率”且未说明利润类型时，默认公式是 `PROFIT BEFORE TAX / TOTAL NET SALES`。
- 金额类指标单位为千元；回答金额时默认按千元展示，必要时可换算为万元、百万元或亿元。`销量` 不是金额指标。

## 用户习惯

- 用户常用自然语言提问，不一定显式写出字段名。
- 用户常把“收入”当作销售净额，把“利润”当作税前利润。
- 用户通常更关心默认口径下的直接答案，而不是完整字段说明。
- 用户只在需要时才希望看到 SQL、字段名或口径补充。

## 维度规则

默认汇总分析只使用高层级：

- `TOTAL`
- `事业群`
- `事业部`

以下四个字段是平级 segment 口径，不是上下级链路：

- `水木基辅`
- `PDT`
- `产线`
- `Org`

只有用户明确问到这些字段时才使用。跨年查询中，如果目标年份没有对应字段值，直接说明该年份没有该 segment 口径，不要强行映射。

用户要求分析到“产线维度”时，按年份切换底层字段：

- `2025` 年及以后：按 `PDT`
- `2024` 年及以前：按 `产线`

回答时可以继续使用“产线维度”这个业务表达，但底层查询字段按上述年份规则切换。

如果用户跨越 `2024/2025` 做产线维度对比，要明确提示该维度口径发生切换；默认不强行拼接为完全可比口径。

## 时间规则

`Period` 同时包含月度、季度、半年和 `YTD`。不要混合不同粒度求和。

- 月度：`Jan` 到 `Dec`
- 季度：`1Q` 到 `4Q`
- 半年：`1H`、`2H`
- 累计：`YTD`

用户没有说明时间粒度时，按问题语义选择最自然的单一粒度；无法判断时先给出所采用的默认口径。

用户同时问预算和同期时，分别按明确语义过滤，不混用不同 `data_type`。

## 输出规则

用户问核心行、简化利润表或利润表摘要时，固定使用以下行次：

1. `TOTAL NET SALES`
2. `RMCC`
3. `VARIABLE COSTS (ex RMCC)`
4. `CONTRIBUTION MARGIN`
5. `TOTAL OVERHEADS`
6. `EARNINGS B/F INTEREST/TAX`
7. `PROFIT BEFORE TAX`
8. `PROFIT AFTER TAXATION`

展示时优先使用中文名称。

## 衍生指标

衍生指标在查询或回答阶段计算，不要求数据库中存在对应列。

- 税前利润率 = `profit_before_tax / total_net_sales`
- 息税前利润率 = `earnings_before_interest_tax / total_net_sales`
- 税后利润率 = `profit_after_taxation / total_net_sales`
- 毛利率 = `gross_profit / total_net_sales`
- 固费率 = `total_overheads / total_net_sales`
- 折扣率 = `less_discount / total_gross_sales2`
- 单位收入 = `total_net_sales / volume`
- 单位毛利 = `gross_profit / volume`
- 预算差异 = `实际 - 预算`
- 预算差异率 = `(实际 - 预算) / 预算`
- 预算达成率 = `实际 / 预算`

计算率类指标时，用 `NULLIF(分母, 0)` 避免除零。

## 回答习惯

- 优先回答用户问题本身，不主动展开全量字段说明。
- 先给结论，再补充当前问题需要的口径、过滤条件和计算公式。
- 指标名称优先用中文；必要时在括号中补充 SQL 字段名。
- 金额类结果标注单位“千元”，比例类结果标注为百分比，销量按原表单位展示。
- 如果字段或年份不可用，直接说明不可用原因和已查询的范围。
- 如果用户要求明细 SQL，可以给出实际使用的 SQL。
