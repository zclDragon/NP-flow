# 固定页面主题

页面主题固定，但每次允许根据 `dimension_support.json` 跳过。

## 页面主题清单

### 1. 数据概览

作用：

- 交代文件范围
- 交代分析周期
- 交代支持范围

状态：

- 建议始终保留

### 2. 会员概况

作用：

- 展示会员盘规模与标签覆盖

状态：

- 高优先级

### 3. 一物一码来源已挂靠

作用：

- 展示已挂靠承接与转化表现

状态：

- 可跳过

### 4. 一物一码来源待挂靠

作用：

- 展示未挂靠扫码会员的工种与区域结构

状态：

- 可跳过

### 5. 会员消费

作用：

- 展示消费主盘、店型差异、等级贡献

状态：

- 高优先级

### 6. 上门基检 / 上门服务

作用：

- 展示服务动作与转化表现

状态：

- 可跳过

### 7. 会员日

作用：

- 展示会员日覆盖、参与、中奖和核销

状态：

- 可跳过

### 8. 会员分层与风险池

作用：

- 输出后续运营优先级

状态：

- 高优先级，但依赖行为字段

### 9. 门店经营机会优先级

作用：

- 输出门店排序和优先投入建议

状态：

- 可跳过

### 10. 联谊会 / 线下活动

作用：

- 展示线下活动强弱与活动质量

状态：

- 常见跳过项

### 11. 商城 / GMV

作用：

- 展示线上成交规模与趋势

状态：

- 常见降级项

## 主题跳过规则

如果主题被跳过，必须在 `report_plan.json` 中写明：

- `status = skipped`
- `reason`
- `missing_fields`

如果主题只支持部分内容，必须写明：

- `status = partial`
- 哪些部分可算
- 哪些图表被降级或取消

## 渲染提示

页面主题只定义内容，不绑定介质。

下游渲染时可按介质做不同表现：

- PPT：页
- HTML：section
- PDF：章节
- 文档：大纲块
